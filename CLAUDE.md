# Project Context

## Purpose
Build a lab-ready full-stack starter that demonstrates accessible React UI work with a Python API backend and modern testing defaults.

## Tech Stack
- FastAPI (Python backend)
- React (frontend)
- Vitest (test runner)

## Naming Conventions
1. Use `PascalCase` for React component file names and component symbols.
2. Use `camelCase` for TypeScript variables, functions, and props.
3. Use `snake_case` for Python modules and function names.

## Pattern To Always Avoid
Avoid inline CSS styles in UI code. Use Tailwind utility classes instead.
